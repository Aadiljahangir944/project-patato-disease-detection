# project-patato-disease-detection
Project Overview  This project is a Computer Vision-based image classification system that detects potato leaf diseases using a Convolutional Neural Network (CNN).  The model classifies potato leaves into three categories:   Healthy   Early Blight   Late Blight  The goal of this project is to help in early disease detection using leaf images, which can assist farmers in taking timely action.   Model Architecture  The model is built using TensorFlow/Keras Sequential API and includes:  Conv2D Layers  MaxPooling Layers  Flatten Layer  Dense Layers  Softmax Output Layer  Additional Techniques Used:  Image Rescaling (1/255 normalization)  Data Augmentation (RandomFlip, RandomRotation)  Proper Train/Validation/Test split (80-10-10)  Dataset optimization using cache() and prefetch(AUTOTUNE)   Model Performance  ✅ Training Accuracy: ~97%  ✅ Low training loss (~0.05)   Stable validation accuracy after augmentation   Tested on unseen images   Tech Stack  Python  TensorFlow / Keras  NumPy  Matplotlib   Project Structure ├── patato_disease.ipynb ├── models/ │   └── saved_model.keras ├── dataset/ │   ├── Early_Blight/ │   ├── Late_Blight/ │   └── Healthy/   How to Run  Clone the repository  Install dependencies:  pip install tensorflow matplotlib numpy   Run the Jupyter Notebook:  jupyter notebook patato_disease.ipynb  Future Improvements  Deploy using Streamlit or FastAPI  Add Transfer Learning (MobileNet / ResNet)  Add Confusion Matrix & F1-Score evaluation  Build a web-based UI for real-time predictions  Author  Aadil Jahangir B.Tech – Electronics & Communication (AI & ML)
